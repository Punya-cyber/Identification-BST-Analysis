a) BST Implementation
The identification numbers are inserted into a Binary Search Tree.
Inorder traversal displays the numbers in lexicographical order.

b) BST Search vs Linear Search
BST search takes O(log n) in the average case and O(n) in
the worst case.
Linear search takes O(n) in the average case and worst case.

c) Effect of Key Length and Insertion Order
Longer identification numbers may require more character
comparisons.

The insertion order affects the height of a normal BST.
A balanced BST has O(log n) search complexity, while a
skewed BST can have O(n) complexity.

For a growing database, AVL trees, Red-Black trees, or
B-trees can be used to maintain efficient searching.
